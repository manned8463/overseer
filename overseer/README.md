# Overseer

A SillyTavern UI extension boilerplate.

## Features

- Settings panel in the "Manage Extensions" menu
- Persistent extension settings
- Lifecycle hooks (install, update, delete, enable, disable, activate, clean)
- Event listener example (`MESSAGE_RECEIVED`)

## Installation

### Install for all users

    git clone https://github.com/your/overseer data/default-user/extensions/third-party/overseer

### Install for the current user only

1. Open SillyTavern.
2. Go to "Manage Extensions" (magic wand icon).
3. Enter the repository URL: `https://github.com/your/overseer`.
4. Click "Install".

## Usage

1. Open "Manage Extensions".
2. Expand the "Overseer" panel.
3. Toggle "Enabled" and adjust "Option" as needed.
